## Framing (dari wawancara)

Repo ini adalah **personal use case**, **bukan** inisiatif branding atau
komersial. Pemilik menegaskan tidak ada strategi branding/monetisasi yang sedang
dijalankan lewat repo ini. Karena itu kategori bisnis di sini sengaja minimal.

## Model bisnis

- **Non-komersial / personal.** Tidak ada monetisasi terintegrasi (tanpa
  affiliate automation, tanpa checkout, tanpa produk berbayar) di dalam scope
  repo.
- Konten dapat secara tidak langsung mendukung kehadiran profesional Dena
  (Founder `@nafanesia.id`, Co-founder `@tumbuhaiofficial` — dari style guide),
  tetapi repo tidak menjalankan pipeline leads/marketing formal.
- Catatan historis: video contoh aktif ("repliz affiliate joke") memakai
  affiliate sebagai **lelucon**; CTA default non-promissory. Ini bukan model
  monetisasi.
